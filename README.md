# Python Practice & Foundational Exercises

A collection of foundational Python programming exercises demonstrating core programming constructs, Object-Oriented Programming (OOP), arithmetic functions, file operations, and exception handling.

[![Python](https://img.shields.io/badge/Python-3.x-3776AB?style=flat&logo=python&logoColor=white)](https://python.org)

---

## 📚 Exercises Included

- **`BankAccount.py`**: Object-Oriented Programming (OOP) demonstrating class definition, constructor initialization (`__init__`), instance methods (`deposit`, `withdraw`), and balance state tracking.
- **`calculator.py`**: Interactive console-based arithmetic calculator handling user inputs, conditional operators (`+`, `-`, `*`, `/`), and division-by-zero validation.
- **`exception handling`**: Try/except error-handling patterns for graceful failure management.
- **`file handling program`**: Reading from and writing to disk files using Python file contexts.

---

## 🏃 Running the Scripts Locally

### Prerequisites
- Python 3.8 or newer (no external dependencies required)

### Execution
Run any of the practice scripts directly using Python:

```bash
# Bank Account OOP Exercise
python BankAccount.py

# Calculator CLI
python calculator.py
```
